About the project & the builder

WeatherGate is a full-stack web application built with Django, PostgreSQL, and Python. It integrates the OpenWeatherMap API to deliver real-time weather data through a clean, dark-themed dashboard.

The project covers the full backend lifecycle. Custom user authentication with MFA via email, environment variable management, database migrations, pytest unit tests, and production deployment on Railway.

It was built publicly, documented on LinkedIn under #HKingsJourney, as proof that consistent work.

My name is Hamilton P C Reis. I'm a Python backend developer and the author of WeatherGate. The idea came from a simple desire: to apply what I was learning in practice, thinking ahead about the full picture. API integration, MFA authentication, production deployment.
